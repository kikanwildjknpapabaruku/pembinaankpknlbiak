# Manajemen Kinerja Organisasi KPKNL Biak

Presentasi HTML interaktif 15 slide untuk pembinaan KPKNL Biak pada 13 Oktober 2026.

Materi mencakup manajemen kinerja organisasi berdasarkan KMK 127 Tahun 2026, perbandingan dengan KMK 300/KMK.01/2022, serta rencana aksi kinerja dan risiko Seksi Kepatuhan Internal berdasarkan sheet Bagian IV kertas kerja reviu DJKN 2026.

## Penggunaan

Buka `index.html` menggunakan Microsoft Edge atau Google Chrome. Presentasi dapat berjalan secara offline. Simpan `index.html`, `styles.css`, dan `script.js` dalam folder yang sama.

| Kontrol | Fungsi |
| --- | --- |
| Panah kiri / kanan | Navigasi slide |
| Spasi / Page Down | Slide berikutnya |
| Page Up | Slide sebelumnya |
| Home / End | Slide pertama / terakhir |
| F | Layar penuh |
| G | Daftar slide |
| N | Catatan pemateri |
| S | Sumber materi |
| Esc | Tutup dialog |

Tombol **Cetak / PDF** mencetak seluruh 15 slide. Aktifkan grafik latar belakang dan nonaktifkan header/footer browser agar tampilan cetak sesuai.

## Interaksi

- Pemilihan tahap siklus manajemen kinerja.
- Filter tabel perbandingan aturan.
- Simulasi K3 per IKU.
- Kuis diskusi dengan umpan balik.
- Checklist kesiapan yang tersimpan pada browser jika penyimpanan lokal tersedia.

## Sumber dan penafsiran data

- [KMK 127 Tahun 2026, naskah resmi Kementerian Keuangan](https://djpb.kemenkeu.go.id/portal/Peraturan/KMK/KMK127-2026.pdf).
- [KMK 300/KMK.01/2022, naskah resmi Kementerian Keuangan](https://djpb.kemenkeu.go.id/portal/images/dokumen_PPID/regulasi/KMK_300_2022.pdf).
- Sheet Bagian IV dari kertas kerja reviu implementasi manajemen kinerja organisasi dan manajemen risiko DJKN tahun 2026 yang digunakan dalam pembinaan.

Rujukan halaman dan rentang sel terdapat pada slide dan catatan pemateri. Isian contoh, angka yang tidak selaras dengan uraian, tanggal masa depan, serta isian kosong ditandai untuk verifikasi. Tenggat pada workbook dibedakan dari usulan jadwal kerja internal.

## Penyuntingan

- `index.html`: kerangka presentasi.
- `styles.css`: desain dan tata letak.
- `script.js`: isi slide, catatan, sumber, dan interaksi.
- `PETUNJUK.txt`: panduan penggunaan berbahasa Indonesia.

Tidak memerlukan proses build atau dependensi tambahan.
